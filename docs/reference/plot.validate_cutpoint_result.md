# Plot Bootstrap Threshold Distributions

Generates a density plot map visualizing the empirical sampling
distributions of optimal cut-points derived from bootstrap runs.

## Usage

``` r
# S3 method for class 'validate_cutpoint_result'
plot(x, ...)
```

## Arguments

- x:

  A `validate_cutpoint_result` object.

- ...:

  Additional arguments passed down to downstream rendering pipelines.

## Value

A `ggplot2` graphics canvas object.
